## Overview

This project is a **Python-based lexical scanner** developed as part of a CS365 course assignment.  
It reads a source code file and tokenizes the contents, identifying:

- Identifiers (`<id>`)  
- Reserved words (`read`, `write`, `if`, `else`)  
- Numbers (integers and floats)  
- Operators (`+`, `-`, `*`, `/`, `%`, `=`)  
- Parentheses (`(`, `)`)

The scanner outputs each token along with its **type, row, and column** in the source code.
